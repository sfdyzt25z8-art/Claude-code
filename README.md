# Projects in this repository

This repository hosts multiple independent apps.

## Organizer

An AI-powered life operating system (student / business / personal modes) spanning
web, mobile, and backend.

- App source: [`organizer/`](organizer/README.md)
- Architecture, scope, and status: [`organizer/docs/ARCHITECTURE.md`](organizer/docs/ARCHITECTURE.md)

## AI Video Generator

A premium, Apple-quality iOS app for generating videos and thumbnails from text
prompts using AI, built with SwiftUI + MVVM.

- App source: [`AIVideoGenerator/`](AIVideoGenerator/README.md)
- Architecture, scope, and status: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## CEO Empire

A business simulation game — start with $10,000, buy and upgrade businesses, hire employees,
invest, and climb the leaderboard to become the richest CEO in the world. Built with React,
TypeScript, Vite, Tailwind CSS, and Firebase.

- App source: [`ceo-empire/`](ceo-empire/README.md)

## Velocity Rush

A modern arcade car racing game — 20 cars, 15 tracks, 11 game modes (Career, Quick Race, Time
Trial, Drift, Checkpoint, Endless Highway, Elimination, Tournament, Police Chase, Test Drive,
Multiplayer), AI opponents, upgrades, cosmetic customization, and a full save/economy/progression
loop. Built with Phaser 3, TypeScript, and Vite — every graphic and sound is generated at runtime,
with no external art or audio assets.

- App source: [`velocity-rush/`](velocity-rush/README.md)
